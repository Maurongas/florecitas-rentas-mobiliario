# Incidencias detectadas durante el desarrollo

Registro de errores **reales** que aparecieron al construir y probar el sistema, con su causa y corrección.

| ID | Fecha | Componente | Síntoma | Causa | Corrección |
|----|-------|------------|---------|-------|------------|
| INC-01 | 2026-11-21 | `02_rutinas.sql` – `sp_crear_reservacion` | Al crear el procedimiento MySQL respondió `ERROR 3569: Table j appears in multiple locking clauses`. | El `SELECT ... FOR UPDATE` que bloquea los artículos hacía JOIN con `JSON_TABLE`; MySQL intenta bloquear todas las tablas del FROM y una tabla derivada de JSON no se puede bloquear. | Se cambió a `FOR UPDATE OF a`, que bloquea solo las filas de `articulo` (lo que realmente se necesita para evitar que dos reservaciones simultáneas aparten las mismas piezas). |
| INC-02 | 2026-11-21 | `Program.cs` – autenticación | La pantalla de inicio de sesión aparecía sin estilos (solo texto plano). | Se definió una política de autorización por defecto (`FallbackPolicy`) que exige sesión; en .NET 10 `MapStaticAssets()` registra los CSS/JS como *endpoints*, así que también quedaron protegidos y el navegador recibía una redirección al login en lugar del archivo. | Se agregó `.AllowAnonymous()` a `MapStaticAssets()`: los archivos estáticos son públicos y las páginas siguen requiriendo sesión. |
| INC-03 | 2026-11-21 | `Data/ErroresBd.cs` – traducción de errores | En la prueba UI-17 (eliminar un cliente con reservaciones) la interfaz mostró el mensaje técnico `Error de base de datos (1217): Cannot delete or update a parent row...` en lugar del mensaje amigable. | Con el usuario `root` MySQL devuelve el error **1451**, pero la aplicación se conecta con `rentas_app` (privilegios mínimos) y, al no poder ver el detalle de la FK, MySQL devuelve el código genérico **1217**. Solo se había mapeado el 1451. | Se mapearon los códigos 1217/1451 (y 1216/1452) al mismo mensaje: "No se puede eliminar porque tiene registros relacionados". Se volvió a ejecutar la prueba UI-17 y pasó. |
| INC-04 | 2026-11-21 | Entorno de desarrollo (Windows) | `curl` y otras herramientas fallaron con `File name too long` al trabajar dentro de la carpeta del proyecto. | La ruta de la carpeta superaba el límite de 260 caracteres de Windows. | Se trabajó desde una unidad virtual corta (`subst R:`) y se documentó en el README clonar el repositorio en una ruta corta (p. ej. `C:\dev\`). |
